1. What is a Recommendation System?

Recommender systems are algorithms that predict user interest in items. The two primary paradigms are Collaborative Filtering (which requires user ratings matrices and fails on cold items) and Content-Based Filtering (which recommends items based on attribute similarity between content tags).

⚙️

2. Why Content-Based Filtering?

Content-based filtering requires zero historical user rating logs, completely resolves the user cold-start constraint, and provides direct, explainable transparency into why each movie was surfaced (e.g. shared director, genres, and narrative keywords).

🧬

3. Data Preprocessing & Entity Isolation

Stringified JSON columns (genres, keywords, cast, crew) are parsed via ast.literal_eval. Critical entity whitespace is collapsed (e.g. "Sam Worthington" → "SamWorthington") so tokens do not collide with unrelated figures sharing common first or last names.

✂️

4. Morphological Stemming (Porter Stemmer)

The Porter Stemming algorithm applies linguistic morphological transformations to unify inflectional variants into canonical roots (e.g., "activities", "activity" → "activ"; "directing", "director" → "direct"), reducing vocabulary sparsity.

📊

5. Bag-of-Words & CountVectorizer

Documents are mapped into a term-frequency space using Scikit-Learn's CountVectorizer(max_features=5000, stop_words='english'). English stopwords (the, is, and) are pruned, resulting in a sparse count matrix $\mathbf{V} \in \mathbb{R}^{4806 \times 5000}$.

📐

6. Cosine Similarity Metric

Evaluates directional alignment between feature vectors in inner product space:
cos(θ) = (u · v) / (||u|| × ||v||)
Unlike Euclidean distance, Cosine Similarity is document-length invariant, ensuring long plot synopses do not penalize similarity with concise overviews.

Model Strengths

  • Dynamic Fallback: Resolves closed-world dataset limits by querying TMDB API and projecting live into fitted vector space.
  • Zero Cold-Start: Recommends any film with metadata without requiring user rating histories.
  • Sub-Millisecond Inference: Precomputed matrix enables instant $O(1)$ row indexing.
  • Typo Resilience: Gestalt pattern matching (difflib cutoff 0.6) catches spelling mistakes.
  • Clean Entity Isolation: Whitespace collapsing prevents surname token collision.

Current Limits & Future Scope

  • Lexical Gap: Synonyms (e.g. cosmonaut vs astronaut) do not match unless exact tokens align.
  • Feature Dilution: 80-word overviews outnumber single-word directors unless explicit weights are applied.
  • Omission of Quality Signals: Currently ignores vote_average and vote_count during ranking.
  • Future Scope: Integrate SBERT dense embeddings, ANN indexing via FAISS, and Bayesian popularity blending.
